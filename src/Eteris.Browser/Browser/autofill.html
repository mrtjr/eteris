Pagamentos

CartõesO código de segurança do cartão nunca se guarda: escreve-se no momento de pagar. O número completo só com o Windows Hello.
IBANContas bancárias para transferências e débitos diretos.
Preencher automaticamente pagamentosSugere os cartões e o IBAN nos formulários de pagamento. Nada se preenche sem escolher, e só em ligações seguras (https).
Pedir o Windows Hello ao preencher pagamentosSó neste computador. Desligar também pede o Windows Hello.
Sincronizar entre computadoresCom a sincronização ligada, os cartões e o IBAN passam para os outros computadores só se ligar «Pagamentos» em «O que passa entre PCs» (desligado por omissão; ligar pede o Windows Hello). Vão com uma segunda cifra própria e nunca com o código de segurança.

Informações de contacto

MoradasNome, morada, e-mail e telefone para preencher formulários, com os campos de Portugal (código postal, distrito) e do Brasil (CEP, bairro, estado).
Preencher automaticamente moradasSugere as moradas guardadas. Nada se preenche sem escolher.
Sincronizar entre computadoresCom a sincronização ligada, as moradas passam para os outros computadores (linha «Informações de contacto» em «O que passa entre PCs», ligada por omissão), com uma segunda cifra própria.

Documentos de identificação

DocumentosPassaporte, carta de condução/CNH, Cartão de Cidadão/RG e o número fiscal (NIF/CPF). Os números ficam mascarados; vê-los pede o Windows Hello.
Preencher automaticamente documentosSó o NIF/CPF é reconhecido sozinho nos formulários; os outros preenchem-se com o botão direito › «Preencher com…».
Sincronizar entre computadoresCom a sincronização ligada, os documentos só passam para os outros computadores se ligar «Documentos de identificação» em «O que passa entre PCs» (desligado por omissão; ligar pede o Windows Hello). Vão com uma segunda cifra própria.

Viagens

VeículosMarca, modelo, ano, matrícula/placa e VIN, para seguros, portagens e parques.
Programas de fidelidadeCompanhias aéreas e de viagem: o número de cliente fica mascarado.
Preencher automaticamente viagensOs veículos e os programas preenchem-se com o botão direito › «Preencher com…» › «Viagem». Desligado, essa entrada sai do menu.
Sincronizar entre computadoresCom a sincronização ligada, os veículos e os programas passam para os outros computadores (linha «Viagens» em «O que passa entre PCs», ligada por omissão), com uma segunda cifra própria.
